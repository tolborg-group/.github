# Tolborg Group

Github organization for Kasper Tolborg's group at the Department of Chemistry and Bioscience at Aalborg University.

See the [handbook](https://tolborg-group.github.io/handbook/) for onboarding.

## Templates

- [LaTeX paper template](https://github.com/tolborg-group/paper-template): LaTeX with Pixi managed latex, tasks for building and previewing.
- [Quarto blog template](https://github.com/tolborg-group/blog-template): Quarto blog managed through Pixi for rendering and preview. CI setup for publishing to GitHub pages. 

## Other 

- [Group skills](https://github.com/tolborg-group/group-skills): Skill marketplace to defined reusable and shareable Claude Code skills in the open *Agent Skills* skills format.
